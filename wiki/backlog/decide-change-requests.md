# Decide: does a change request move a work item back?

The CEO chooses between the two options in [Protocol → Open questions](../product/architecture/protocol.md#open-questions): the lead names the branch when asking for a change and the row goes back to "with the author" (A), or rows only move on hand-offs, integration and PR events (B). Needed before the [Git](./epics/git.md) epic shows work items; the answer goes into the protocol and the question is removed.

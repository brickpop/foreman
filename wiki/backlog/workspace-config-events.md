# Workspace and config loading, file watcher, event stream

**Why:** projects, team files and settings are files the CEO owns ([Workspace](../product/models/workspace.md)); the UI must follow them live within ~1 s, and every later screen needs the event stream.

**Done when:** Foreman lists projects (folders with `project/project.toml`), reads `project.toml`, team files and `settings.toml` with their validation errors, notices changes through the file watcher, and pushes them to the UI over `/api/events` (SSE); the UI's client interface exposes them.

- [x] parse and validate [Project config](../product/models/project-config.md), [Team definition](../product/models/team-definition.md) (souls: [Agent soul](../product/models/agent-soul.md)), [Workspace settings](../product/models/workspace-settings.md)
- [x] TOML everywhere (drop YAML); version-guarded writes of team files and settings (`SaveTeam`, `SaveSettings`; the PUT endpoints come with the screens that edit them)
- [x] the workspace repo: `git init` of `.foreman/` with its `.gitignore` (state.db*, logs/, secrets, credentials/, access-token, *.tmp) on workspace creation and for existing workspaces; one commit per UI save (nothing pushed: the Sync action belongs to the [Git epic](./epics/git.md))
- [x] fsnotify watcher, debounced (ignoring state.db and logs churn); event bus; `GET /api/events` ([API → Events](../product/architecture/api.md#events))
- [x] `/api/projects`, `/api/teams`, `/api/settings` read endpoints; UI client methods and `events()`, typed with types generated by `tygo` (`just types`)
- [x] `just test` and `just race` on the CEO's Mac: the watcher runs on kqueue there (Linux: inotify); both pass (2026-10-16). Running there also found that `Exclude` wrote a line matching nothing when the path went through a symlink (macOS's `/var`), now fixed
